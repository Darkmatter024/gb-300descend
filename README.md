# GB300 Descent

A 3D zoom from the power grid down to a single atom, through a GB300 NVL72 data hall.
Four paths below the hall: compute, data, heat and power.

Live: https://darkmatter024.github.io/gb-300descend/

- `index.html` — the whole experience, one self-contained page
- `narration.json` — recorded narrator voices (Emma, Heart), loaded on demand
