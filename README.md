# GB300 Descent

A 3D zoom from the power grid down to a single silicon atom, through a GB300 NVL72 data hall.
Fourteen levels, and six paths below the hall: compute, data, heat, power, memory and NVLink.

Live: https://darkmatter024.github.io/gb-300descend/

- `index.html` — the whole experience, one self-contained page
- `narration.json` — recorded narrator voices (Heart · American, the default; Emma · British), loaded on demand

## Highlights

- Guided one-minute hall tour with narration
- Rendered data hall with rack ID tags (R05 / R06 rows) and live, blinking rack LEDs in the 3D view
- Synthesized data center ambience (fan wall, hum, CDU pumps) that changes with depth
- Each path has its own colour: compute cyan, data yellow, heat orange, power amber, memory purple, NVLink green
